# MIST — Игровые правила

## Мир

- **MIST** — туманный мир, где игроки просыпаются без памяти
- **Континент**: Mistlands
- **Регионы**: Тёмный лес, Побережье, Горные земли, Островки цивилизации, Скрытые земли
- **Локации**: 28 локаций с координатами (x, y, z)

## Игрок

- **HP**: 100 (базовое), восстанавливается исцелением
- **Уровень**: 1-100, XP за бои, квесты, исследования
- **Атака/Защита**: влияют на урон в бою
- **Репутация**: -100..+100 (Враг → Подозрительный → Нейтральный → Доброжелательный → Герой)

## Валюты

- **Золото (🪙)**: основная валюта, за бои/квесты/торговлю
- **Камни (💎)**: редкая валюта, за боссов/секреты
- **Токены (🎫)**:.event- валюта, за мировые события

## Бой

- **PvE**: бои с существами (hostile/neutral/friendly)
- **PvP**: арена, мин. уровень 5, рейтинг +/-25
- **Боссы**: спавнятся по расписанию, дают камни

## Квесты

- **Типы**: kill, collect, explore, talk, deliver, craft
- **Этапы**: каждый квест имеет этапы с прогрессом
- **Макс. активных**: 5

## NPC

- **Типы**: merchant, quest_giver, guard, elder, bartender, healer, shady
- **Память**: relation -100..+100, влияет на цены
- **Расписание**: день/ночь, утро/вечер

## Погода

- **Состояния**: clear, rain, storm, fog, snow
- **Эффекты**: xp_bonus, movement_penalty

## Гильдии

- **Роли**: leader, officer, member
- **Стоимость создания**: 50 золота
- **Бонусы**: по уровню гильдии

## Достижения

- **33 достижения** в 9 категориях
- **Авто-триггеры**: проверяются при действиях игрока
